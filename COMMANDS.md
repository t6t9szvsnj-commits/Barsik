# Команды для кота

Команды **одинаковые во всех трёх версиях** — и в окошке (`desktop_assistant.py`),
и у кошки на рабочем столе (`desktop_cat.py`), и у Барсика (`desktop_barsik.py`).
Разбирает их один и тот же код, поэтому отдельных списков не нужно. Различаются только кнопки и запуск — про это
в конце.

Писать можно по-разному: кот ищет в фразе ключевые слова, а не точное совпадение.
Регистр не важен.

---

## Все команды

| Что написать | Что произойдёт | Где ищет |
|---|---|---|
| `убери рабочий стол` | Разложит файлы по папкам: Картинки, Документы, Архивы, Видео, Аудио, Код, Прочее | Рабочий стол |
| `разбери загрузки` | То же самое | Загрузки |
| `удали скрины старше 7 дней` | Скриншоты старше срока — в Корзину | Стол **и** Загрузки |
| `убери файлы старше 30 дней` | Старые файлы — в папку «Старое до `<дата>`» | Рабочий стол |
| `убери загрузки старше недели` | То же, но в Загрузках | Загрузки |
| `найди дубликаты` | Одинаковые файлы — в Корзину, самый старый остаётся | Стол **и** Загрузки |
| `удали пустые папки` | Пустые папки — в Корзину | Стол **и** Загрузки |

Перед любой из них кот показывает список и ждёт подтверждения. Ничего не
удаляется навсегда — всё уходит в Корзину, и есть кнопка отката.

---

## Какими словами это можно сказать

Достаточно, чтобы в фразе встретилось **любое** слово из строки.

| Действие | Слова-триггеры |
|---|---|
| Разложить по папкам | `убер` · `разлож` · `сортир` · `почист` · `чист` · `порядок` · `разбер` · `прибер` |
| Работать в Загрузках | `загруз` · `download` (добавь к любой команде) |
| Скриншоты | `скрин` · `сним` · `screenshot` |
| Старые файлы | `старше` · `старьё` · `старье` |
| Дубликаты | `дубликат` · `повтор` |
| Пустые папки | `пуст` **и** `папк` (оба слова сразу) |

Поэтому всё это работает одинаково:

```
убери рабочий стол
прибери стол
наведи порядок
разложи файлы
сортируй стол
почисти стол
```

## Сроки

Срок можно назвать в любой команде, где он имеет смысл.

| Как написать | Сколько получится |
|---|---|
| `7 дней`, `3 дня`, `1 день`, `5 суток` | столько дней |
| `2 недель`, `3 недели` | 14, 21 день |
| `недели`, `неделю` (без числа) | 7 дней |
| `2 месяцев`, `3 месяца` | 60, 90 дней |
| `месяца`, `месяц` (без числа) | 30 дней |
| срок не указан — для скриншотов | 7 дней |
| срок не указан — для старых файлов | 30 дней |

Примеры:

```
удали скрины старше 3 дней
убери файлы старше 2 недель
убери загрузки старше месяца
```

## Порядок разбора (почему команда сработала именно так)

Кот проверяет условия сверху вниз и останавливается на первом подходящем:

1. дубликаты
2. пустые папки
3. скриншоты
4. старые файлы
5. разложить по папкам

Отсюда две вещи, которые выглядят неочевидно:

- `убери скрины старше 7 дней` — это **скриншоты в Корзину**, а не уборка стола,
  потому что скриншоты проверяются раньше.
- `убери файлы старше недели` — это **архив старых файлов**, а не раскладывание
  по папкам, потому что «старше» проверяется раньше.

## Куда что попадает

| Команда | Куда |
|---|---|
| Разложить по папкам | `Рабочий стол/Разобрать/<Категория>/` (или `Загрузки/Разобрать/…`) |
| Старые файлы | `Разобрать/Старое до 18.09.2026/` — в той папке, с которой работали |
| Скриншоты, дубликаты, пустые папки | Корзина |

## Мелочи, о которых стоит знать

**Что считается скриншотом.** Имя файла должно *начинаться* с одного из:
`Снимок экрана`, `Снимок`, `Screenshot`, `Screen Shot`, `CleanShot`,
`Запись экрана`. Переименованный скриншот («отпечаток.png») кот уже не узнает.

**Дубликаты** ищутся по содержимому, а не по имени: два одинаковых файла с
разными названиями будут найдены, а два разных с одинаковым — нет. Пустые файлы
(0 байт) игнорируются. Остаётся самый старый, остальные уезжают в Корзину.

**Пустые папки** — только те, что лежат прямо на Столе или в Загрузках, вглубь
кот не лезет. Папка, в которой остался только `.DS_Store`, считается пустой.

**Скрытые файлы** (начинающиеся с точки) не трогаются никогда.

**Папка «Разобрать»** сама по себе не разбирается и не считается мусором.

**Чего кот не делает:** не заходит никуда, кроме Рабочего стола и Загрузок;
не переименовывает файлы; не открывает их; не удаляет мимо Корзины.

## Кнопки и запуск — вот это у версий разное

### Версия 1 — `desktop_assistant.py`

| Элемент | Что делает |
|---|---|
| Поле ввода + `Enter` | Выполнить команду |
| `Убрать стол` · `Разобрать загрузки` · `Скрины 7 дн.` · `Дубликаты` | Быстрые команды в одно нажатие |
| `Отменить последнее` | Вернуть файлы туда, где лежали. Жать можно несколько раз подряд — отматывает операции по одной |
| `Что я умею` | Короткая справка в окне |
| `Настройки доступа` | Открыть разрешения macOS |

### Версия 2 — `desktop_cat.py`

| Элемент | Что делает |
|---|---|
| Панель «Ask anything…» + `Enter` | Выполнить команду |
| `Давай` / `Не надо` | Подтвердить или отменить (или `Enter` / `Esc`) |
| `Вернуть как было` | Вернуть файлы туда, где лежали. Жать можно несколько раз подряд — кошка показывает, сколько ещё можно отменить |
| `Exit` | Выход |
| `Esc` | Стереть набранное; на пустой строке — выход |
| Клик по кошке | Погладить |
| Перетащить панель мышкой | Переместить её по экрану |

Запуск версии 2:

```bash
python3 versions/desktop_cat.py            # обычный режим
python3 versions/desktop_cat.py --demo     # показательный прогон, файлы не трогаются
python3 versions/desktop_cat.py --check    # проверить, что этот Mac всё умеет
```

### Версия 3 — `desktop_barsik.py`

Кнопки те же, что у версии 2: панель «Ask anything…», `Давай` / `Не надо`,
`Вернуть как было`, `Exit`, `Esc`. Клик по Барсику — погладить: он зажмурится.
Клик по гортензии, которую он принёс, — забрать цветок.

Запуск версии 3:

```bash
python3 versions/desktop_barsik.py            # обычный режим
python3 versions/desktop_barsik.py --demo     # показательный прогон, файлы не трогаются
python3 versions/desktop_barsik.py --check    # проверить Mac и что кадры Барсика на месте
python3 versions/desktop_barsik.py --flower   # сразу сходить за гортензией (посмотреть)
python3 versions/desktop_barsik.py --no-glass # прежняя панель, без стекла
```

Барсик.app запускают двойным кликом, и флаг туда не передать — поэтому прежняя
панель включается строчкой `BARSIK_PANEL=plain` в файле `~/.desktop_assistant_ai`
(подробнее в README). Разово можно и флагом, запустив приложение из Терминала:

```bash
/Applications/Барсик.app/Contents/MacOS/Barsik --no-glass
```

## Свободный текст

Если задан ключ API (см. [README](README.md)), кот понимает и формулировки не из
этого списка — например «перекинь все пдфки в отдельную папку». Правила
безопасности те же: модель только предлагает план, всё за пределами Рабочего
стола и Загрузок отбрасывается, и план всё равно показывается на подтверждение.

Без ключа на незнакомую фразу кот честно скажет, что не понял.
