# Как подключить ИИ через OpenRouter (Haiku или Sonnet)

Без ИИ Барсик понимает команды из [COMMANDS.md](COMMANDS.md). С ИИ он понимает
и свободные фразы вроде «сложи все pdf про учёбу в одну папку». К модели он
обращается только тогда, когда не понял команду сам, поэтому это недорого:
около цента за такую команду.

Всё делается один раз.

## 1. Ключ на OpenRouter

1. Зайти на **openrouter.ai** и зарегистрироваться.
2. Пополнить баланс: **Credits → Add credits**. Хватит самой маленькой суммы.
3. **Keys → Create key**, назвать, например, `Барсик`. Если там есть поле с
   лимитом трат для ключа, поставить небольшой — для спокойствия.
4. Скопировать ключ, он начинается на `sk-or-…`. Сайт покажет его **один раз**,
   поэтому сразу сохранить.

## 2. Точное название модели

На **openrouter.ai/models** найти нужную модель и скопировать её
идентификатор (кнопкой рядом с названием). Скорее всего это:

| Модель | Что выбрать | Идентификатор |
|---|---|---|
| Claude Sonnet 5 | лучше понимает расплывчатые просьбы, ~1 цент за команду | `anthropic/claude-sonnet-5` |
| Claude Haiku 4.5 | быстрее и вдвое дешевле, но проще | `anthropic/claude-haiku-4.5` |

Названия брать **с сайта**, а не из этой таблицы: если ошибиться хоть в одном
символе, Барсик получит от сервера ошибку.

## 3. Положить ключ на Мак

Открыть Терминал (Cmd+Пробел → «Терминал»), вставить **целиком**, подставив
свой ключ и модель:

```bash
cat > ~/.desktop_assistant_ai <<'EOF'
ASSISTANT_PROVIDER=openai
OPENAI_API_KEY=sk-or-ТВОЙ_КЛЮЧ
ASSISTANT_BASE_URL=https://openrouter.ai/api/v1
ASSISTANT_MODEL=anthropic/claude-sonnet-5
EOF
chmod 600 ~/.desktop_assistant_ai
```

- `ASSISTANT_PROVIDER=openai` — не опечатка. Это значит «говорить с сервером
  на общем языке», и OpenRouter его понимает. ChatGPT тут не участвует.
- `chmod 600` — чтобы файл с ключом могла прочитать только владелец Мака.

Этот файл читают все три версии, и Барсик.app, и запуск из Терминала.

## 4. Проверить

В том же Терминале, если Барсик стоит как приложение:

```bash
/Applications/Барсик.app/Contents/MacOS/Barsik --check
```

Если Барсик запускается из папки с репозиторием:

```bash
python3 versions/desktop_barsik.py --check
```

Должно быть:

```
ключ ИИ:            задан
связь с ИИ:         есть
```

«Связь есть» значит только, что до сервера можно достучаться. Правильность
ключа проверяется делом: запустить Барсика и написать что-нибудь, чего нет в
списке команд. Если ключ или название модели неверные, Барсик не поймёт, а на
панели появится ошибка от сервера.

## Переключиться между Haiku и Sonnet

```bash
open -e ~/.desktop_assistant_ai
```

Файл откроется в TextEdit. Поменять строчку `ASSISTANT_MODEL=…`, сохранить
(Cmd+S), затем **закрыть и заново открыть Барсика** — настройки читаются при
запуске.

## Если не работает

| Что видно | Что делать |
|---|---|
| `ключ ИИ: нет (режим правил)` | Файла нет или в нём опечатка в названиях строк — повторить шаг 3 |
| `ключ ИИ: ЕСТЬ, НО в ключе русские буквы…` | Вместо ключа осталось `ТВОЙ_КЛЮЧ` из шага 3 — вставить настоящий ключ |
| `связь с ИИ: НЕТ — …` | Нет интернета, или его режет VPN/фильтр. Текст после «НЕТ —» подскажет |
| На панели «Ответ сервера 401» | Неверный ключ — скопировать заново с openrouter.ai |
| На панели «Ответ сервера 400» или 404 | Неверное название модели — скопировать с openrouter.ai/models |
| На панели «Ответ сервера 402» | Закончились деньги на балансе OpenRouter |

Даже с ИИ Барсик ничего не делает сам: модель только предлагает план, всё за
пределами Рабочего стола и Загрузок отбрасывается, удаляется только в Корзину,
и план всё равно показывается на подтверждение.
