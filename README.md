# Кот-ассистент для рабочего стола (macOS)

[![Тесты](https://github.com/t6t9szvsnj-commits/-/actions/workflows/tests.yml/badge.svg)](https://github.com/t6t9szvsnj-commits/-/actions/workflows/tests.yml)

Пишешь по-русски «убери рабочий стол» — кот разбирает бардак: раскладывает файлы
по папкам, отправляет старые скриншоты в Корзину, находит дубликаты.

В репозитории **три версии**, все рабочие, выбирать по настроению:

| | Версия 1 — `desktop_assistant.py` | Версия 2 — `desktop_cat.py` | Версия 3 — `desktop_barsik.py` |
|---|---|---|---|
| Как выглядит | Обычное окошко, кот нарисован внутри и машет метлой | Рисованная кошка Мурка живёт **прямо на рабочем столе** | **Барсик** — настоящий кот в 3D, с шерстью, собран по его фото и видео |
| Файлы | Разбираются в фоне | Кошка подходит к иконке, берёт файл и **несёт его в папку** — в этот момент файл и переезжает | Так же, как у версии 2 |
| Ввод | Поле в окне | Плавающая панель «Ask anything…» внизу экрана | Та же панель |
| Статус | Стабильная | Экспериментальная (нужен живой Mac, чтобы проверить прозрачность окон) | Экспериментальная, как версия 2 |

Движок у них общий: версии 2 и 3 не копируют логику, а импортируют её из
версии 1. Поэтому правила безопасности одинаковые, и чинить их надо в одном
месте. Версия 3 к тому же берёт у версии 2 весь «мозг» кота и окна — своё у
неё только лицо: кадры Барсика вместо рисованной кошки.

---

## Барсик как обычное приложение (проще всего)

Версию 3 можно не запускать из Терминала, а поставить как обычную программу —
**Барсик.app**. Python для неё не нужен, он уже внутри. Работает на любом Маке
с macOS 11 и новее: и на новых с чипом M1–M4, и на старых с Intel.

1. На странице репозитория на GitHub открыть **Releases → «Барсик для Mac»** и
   скачать `Barsik-mac.zip`.
2. Открыть архив — появится «Барсик». Перетащить его в «Программы».
3. **Первый запуск.** Приложение не подписано платным аккаунтом Apple, поэтому
   macOS скажет, что не может проверить разработчика. Открыть Системные
   настройки → Конфиденциальность и безопасность → внизу нажать **«Всё равно
   открыть»**. Это нужно один раз.
4. Разрешения (Рабочий стол, Загрузки, Finder) система спросит уже у самого
   «Барсик» — согласиться.

Выход — кнопка `Exit` на панели или правый клик по Барсику в Доке → Завершить.
Ключ для режима ИИ приложению даётся файлом, см. «Свободный текст» ниже.

Приложение собирается из этих же файлов автоматически на настоящем Маке в
GitHub Actions (`.github/workflows/app.yml`) при каждом изменении в `main`.

**Прошлые версии не пропадают.** Новая сборка всегда называется «Барсик для Mac»,
а предыдущая остаётся в Releases как «Барсик для Mac — прошлая версия (…)».
Не понравилась новая — скачать оттуда `Barsik-mac.zip` и поставить вместо неё.
Исходники каждой версии — git-тег `barsik-<коммит>`: например, версия до
«стеклянной» панели — `barsik-ccf45d0`.

## Что нужно установить

Это для запуска из Терминала — всех трёх версий. Для Барсик.app ничего ставить
не нужно.

Ровно одну вещь: **Python с сайта python.org**. Больше ничего.

1. Открыть [python.org/downloads/macos](https://www.python.org/downloads/macos/)
2. Скачать «macOS 64-bit universal2 installer» (обычный `.pkg`)
3. Открыть его и нажимать «Продолжить» до конца

Всё. Никаких библиотек, никакого Homebrew, никакого терминала для установки —
программа написана на том, что идёт в комплекте с Python.

**Почему именно с python.org, а не тот, что уже есть в системе.** В macOS
`python3` обычно приходит вместе с инструментами Xcode и тянет за собой старый
Tk 8.5, на котором окна ведут себя криво: залипает курсор в поле ввода, рвётся
отрисовка. Установщик с python.org несёт внутри правильный Tk 8.6.

Проверить, что всё встало как надо:

```bash
python3 -c "import tkinter; print(tkinter.TkVersion)"
```

Должно напечатать `8.6`. Если `8.5` — значит запускается системный Python;
тогда используй `python3.12` вместо `python3` в командах ниже.

Дальше останется только выдать разрешения (см. следующий раздел) — это не
установка, а пара галочек в системных настройках.

## Установка

```bash
git clone https://github.com/t6t9szvsnj-commits/-.git kot
cd kot
```

Обновить до свежей версии потом — из той же папки:

```bash
git pull
```

Все три программы лежат в папке `versions/`, поэтому команды ниже
запускаются из корня репозитория как `python3 versions/…`. Раньше они лежали
прямо в корне — после `git pull` просто переехали.

## Первый запуск

### Версия 1 — спокойная

```bash
python3 versions/desktop_assistant.py
```

Откроется окошко. Внизу кнопки быстрых команд, посередине лог, снизу «Отменить
последнее».

### Версия 2 — кошка на столе

Сначала **проверь, что этот Mac всё умеет** — займёт секунду и сразу покажет,
чего не хватает:

```bash
python3 versions/desktop_cat.py --check
```

Пример хорошего вывода:

```
платформа:          darwin
python:             3.12.3
Tk:                 8.6.13
экран:              1512x982
прозрачность:       есть
окно без рамки:     есть
иконки Finder:      видно 34 шт.
доступ к папкам:    есть
ключ ИИ:            нет (режим правил)
```

Потом посмотри показательный прогон — **файлы при этом вообще не трогаются**:

```bash
python3 versions/desktop_cat.py --demo
```

И только потом — по-настоящему:

```bash
python3 versions/desktop_cat.py
```

Кошку можно погладить (клик по ней). Панель ввода перетаскивается мышкой.
Выход — кнопка `Exit` или `Esc` на пустой строке.

### Версия 3 — Барсик

Всё то же, что у версии 2, только вместо рисованной кошки — Барсик:

```bash
python3 versions/desktop_barsik.py --check    # Mac + на месте ли кадры Барсика
python3 versions/desktop_barsik.py --demo     # показ, файлы не трогаются
python3 versions/desktop_barsik.py            # по-настоящему
```

Барсик ходит по столу с хвостом трубой, сидит, обернув хвост вокруг лап, спит
«буханкой», тянется лапой к файлу, прыгает от радости, а если погладить —
жмурится. Кадры лежат в папке `versions/sprites/barsik` и приезжают вместе с `git pull`.

Цвета у Барсика свои: панель светло-голубая, как матовое стекло (просвечивает
только фон, буквы и кнопки чёткие), а чёрный, винный, молочный и
тёмно-тёмно-зелёный — вкраплениями (кнопки, облачко, строка состояния).

**Прежняя панель, без стекла,** включается одной строчкой в файле настроек
`~/.desktop_assistant_ai` (тот же, где ключ ИИ; если файла нет — создать):

```
BARSIK_PANEL=plain
```

Убрать строчку (или написать `BARSIK_PANEL=glass`) — снова стекло. Настройки
читаются при запуске, так что Барсика надо закрыть и открыть заново. Из Терминала
то же самое: `python3 versions/desktop_barsik.py --no-glass`.

**Гортензия.** Иногда Барсик уходит за край экрана и возвращается с белой
гортензией в зубах, кладёт её рядом с панелью и говорит «это тебе ♥». Щелчок по
цветку — забрали (Барсик замурлычет), не забрали — через 15 минут цветок исчезнет
сам. Когда именно: раз в полторы минуты безделья шанс растёт на 5% и
бросается жребий, после цветка — снова с нуля. В среднем выходит раз в ~8 минут
безделья и не позже чем через полчаса. Пока Барсик работает, думает над
командой или ждёт «Давай / Не надо», эти часы стоят. Посмотреть сразу, не
дожидаясь: `python3 versions/desktop_barsik.py --demo --flower`.

## Разрешения macOS (без них ничего не заработает)

macOS по умолчанию не пускает программы в Рабочий стол и Загрузки. При первом
запуске выскочат системные окна — надо согласиться. Если случайно нажал «Не
разрешать», исправляется руками:

**1. Доступ к папкам (обязательно).**
Системные настройки → Конфиденциальность и безопасность → **Файлы и папки** →
найти «Терминал» (или iTerm, или Python) → включить «Рабочий стол» и «Загрузки».

В программе есть кнопка **«Настройки доступа»**, она открывает нужный раздел.
Если доступа нет, кот честно напишет об этом словами, а не молча ничего не сделает.

**2. Доступ к Finder (только для версий 2 и 3, необязательно).**
Системные настройки → Конфиденциальность и безопасность → **Автоматизация** →
Терминал → включить Finder.

Это нужно, чтобы кошка знала, где на столе лежит каждая иконка, и шла именно к
ней. Без этого разрешения версия 2 всё равно работает — кошка просто ходит к
случайным точкам, а файлы разбираются так же правильно.

## Что понимает кот (режим правил, без интернета)

| Команда | Что делает |
|---|---|
| `убери рабочий стол` | Раскладывает всё по папкам: Картинки, Документы, Архивы, Видео, Аудио, Код, Прочее |
| `разбери загрузки` | То же самое для папки «Загрузки» |
| `удали скрины старше 7 дней` | Скриншоты старше указанного срока — в Корзину |
| `убери файлы старше 2 недель` | Складывает их в папку «Старое до <дата>» |
| `найди дубликаты` | Ищет одинаковые файлы (по содержимому, не по имени), оставляет самый старый |
| `удали пустые папки` | Пустые папки — в Корзину |

Числа и «дней / недель / месяцев» понимаются в любой команде: `старше 3 месяцев`,
`старше 10 дней`, `старше недели`. Добавь к команде слово «загрузки», чтобы
работать в Загрузках вместо Рабочего стола.

Файлы раскладываются в папку **«Разобрать»** внутри Рабочего стола или Загрузок.

➡️ **Полный список команд, синонимов, сроков и кнопок — в [COMMANDS.md](COMMANDS.md).**

## Свободный текст (режим ИИ, по желанию)

➡️ **Пошагово для OpenRouter (Haiku или Sonnet) — в [OPENROUTER.md](OPENROUTER.md).**

Если задать ключ, кот начнёт понимать произвольные формулировки, а не только
команды из списка. Ключ читается из переменных окружения или из файла
настроек `~/.desktop_assistant_ai` (для Барсик.app — только из файла, см. ниже).

**Anthropic (по умолчанию):**

```bash
export ANTHROPIC_API_KEY=sk-ant-...
python3 versions/desktop_cat.py
```

Модель по умолчанию — Sonnet. Переключить на Opus можно одной переменной, менять
код не нужно:

```bash
export ASSISTANT_MODEL=claude-opus-5
```

**OpenRouter или другой OpenAI-совместимый провайдер:**

```bash
export ASSISTANT_PROVIDER=openai
export OPENAI_API_KEY=<ключ_openrouter>
export ASSISTANT_BASE_URL=https://openrouter.ai/api/v1
export ASSISTANT_MODEL=anthropic/claude-opus-5     # обязательно с префиксом вендора
```

Чтобы не вводить каждый раз, строчки можно дописать в `~/.zshrc`.

**Файл настроек — обязательно для Барсик.app.** Приложение, запущенное двойным
кликом, не видит `~/.zshrc`. Те же строчки кладутся в файл, одной командой в
Терминале (пример для OpenRouter):

```bash
cat > ~/.desktop_assistant_ai <<'EOF'
ASSISTANT_PROVIDER=openai
OPENAI_API_KEY=sk-or-...ключ...
ASSISTANT_BASE_URL=https://openrouter.ai/api/v1
ASSISTANT_MODEL=anthropic/claude-sonnet-5
EOF
chmod 600 ~/.desktop_assistant_ai
```

`chmod 600` — чтобы ключ могла прочитать только владелец Мака. Строчки с
`export` в начале тоже понимаются. Если задано и там и там, переменные
окружения важнее файла. Проверить из Терминала:
`python3 versions/desktop_barsik.py --check` покажет «ключ ИИ: задан» и
«связь с ИИ: есть».

Даже в режиме ИИ модель не может ничего удалить: она только предлагает план,
а программа отбрасывает все шаги, которые выходят за разрешённые папки, и
показывает тебе оставшееся на подтверждение.

## Безопасность

Это программа, которая двигает твои файлы, поэтому сделано так:

- **Ничего не удаляется навсегда** — всё уезжает в Корзину, откуда можно достать.
- **Трогаются только Рабочий стол и Загрузки.** Всё остальное недоступно, даже
  если модель или ошибка попросят об этом. Симлинк, ведущий наружу, тоже не
  сработает — проверяется реальный путь.
- **Перед любой работой показывается план** и спрашивается подтверждение.
- **«Отменить последнее» / «Вернуть как было»** возвращает файлы туда, где они
  лежали. Кнопку можно жать **несколько раз подряд** — журнал помнит последние
  20 операций и отматывает их по одной, начиная с самой свежей. После каждого
  нажатия видно, сколько ещё можно отменить.
- Откат **никогда не перезаписывает** файлы: если на старом месте уже лежит
  что-то с таким именем, файл вернётся как `имя (2).txt`.
- Если вернуть что-то не удалось (например, не хватило прав) — операция
  остаётся в журнале, и откат можно повторить позже.

## Если что-то пошло не так

**«Нет доступа к папке…»** — см. раздел про разрешения выше, кнопка «Настройки
доступа» открывает нужное место.

**Версии 2 и 3: кот ходит не туда, где лежат файлы** — не выдано разрешение
«Автоматизация → Finder». Проверь через `--check`. На работу это не влияет,
только на красоту.

**Версии 2 и 3: окно кота серое / не прозрачное** — старый Tk. Проверь
`python3 versions/desktop_cat.py --check`, строчка «прозрачность». Лечится установкой
Python с python.org.

**`No module named tkinter`** — `brew install python-tk` или Python с python.org.

**Что-то разложилось не туда** — нажми «Отменить последнее» / «Вернуть как было».

## Тесты

```bash
python3 -m unittest discover -s tests -t .
```

271 тест: безопасность путей, все команды, реальные перемещения файлов во
временной папке, многошаговый откат, обработка отказов в доступе, разбор ответа
модели, вся анимация кота и кадры Барсика (все на месте, лапы не скользят,
ничего не вылезает за окно, говорит о себе в мужском роде), гортензия (шанс,
весь поход за цветком, что будет, если его позвали работать на полпути) и
читаемость цветов. Зависимостей нет — только стандартная библиотека.

Они же автоматически прогоняются **на настоящей macOS** при каждом пуше
(значок вверху). Там же отдельная проверка подтверждает, что прозрачные окна
без рамки, режим «поверх всех» и полупрозрачность действительно работают на
живом Tk 8.6 — то, что нельзя проверить нигде, кроме Мака.

Чего автотесты не заменят: как это всё **выглядит**. Проверка подтверждает,
что окно создаётся и система принимает все настройки, но не то, что кошка
нарисована красиво — на это нужны глаза.

Что тестами **не** покрыто и проверяется только руками на живом Маке: прозрачные
окна, окна без рамки, фокус клавиатуры в панели, системные диалоги разрешений и
точные координаты иконок Finder.
